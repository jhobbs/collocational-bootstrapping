# Source of the original CSV and the newer TalkBank files

Audit date: 2026-09-07. This note clarifies the source differences behind the
first comparison. The completed follow-up using matched utterances and ages is
documented in [MATCHED_RESULTS.md](MATCHED_RESULTS.md).

## Original export

### Connection to Claire's paper

"Original saved analysis" means the existing spaCy output tables under
`Experiment 2 - CHILDES/output/`, preserved in `output/english_spacy_baseline/`
relative to that experiment directory. Direct comparison now confirms that all
eight age-bin exponents, utterance counts, pair counts, and subject/verb
vocabulary counts exactly match Table 3 in the local
[Hobbs and McCoy preprint, arXiv v1](</home/jason/imagining-syntax/2605.20529v1.pdf>)
(PDF page 14), the earlier *Collocational Bootstrapping* draft (PDF page 12),
and Claire's thesis (PDF page 33, printed page 32). The reported overall alpha
is also 1.43. These are the paper's reported results, read from saved repository
outputs rather than newly generated by the matched-data run.

The scope wording differs between versions: the thesis and earlier draft say
English-North America; the arXiv v1 paper's Section 5.1 says participants tagged
as English-language speakers. The latter is consistent with the broader
participant-based selection in the repository. Eng-NA remains a separate
requested reproduction target, not an independently verified Eng-NA-only
version of the saved baseline.

### CSV export provenance

The CSV schema and filename match the repository's
[`childes_get_utterances.R`](../childes_get_utterances.R): it calls
`childesr::get_utterances(corpus=..., role=...)`, retains `target_child_age`,
and writes `childes_full_utterances_<timestamp>.csv`. The filename
`20251211_120050` is consistent with an export on 2025-12-11 at 12:00:50; it is
not a database release identifier. The exported 13 columns match the script.

`childesr` accesses [childes-db](https://langcog.github.io/childes-db-website/about.html),
a versioned tabular representation of CHILDES. This is a different access path
from downloading the current CHAT ZIPs directly from TalkBank. The local export
script does not pin a database version, and no export session log or lockfile
was found in the inspected repositories. The exact database release and package
version used to create this particular CSV are therefore unconfirmed. Current
service configuration alone cannot prove which release a past export used.

Two byte-identical local copies exist:

- `/home/jason/imagining-syntax/childes_full_utterances_20251211_120050.csv`
- `/home/jason/collocational-bootstrapping/childes_full_utterances_20251211_120050.csv`

Both contain 611,614,936 bytes with SHA256
`e4a552d93ee63aa21e0c08e446d52589fd60ea9ef06f96fa1c1e7331d3e46ecb`.
The experiment's `data/childes_utterances.csv` symlink resolves to the second
copy. Earlier working notes that called this symlink dangling were incorrect.
The local files have August 2026 filesystem timestamps, which do not establish
the original export date or who copied them here.

Reapplying the original Python loader reproduces all nine saved utterance
counts, including 4,739,189 overall. This is strong consistency evidence that
the CSV corresponds to the saved analysis, although it does not reconstruct the
export session or prove the identity of every historical pair.

## Current downloads and missing ages

The 98 current archives came from the advertised transcript download links on
official CHILDES corpus pages, such as
`https://talkbank.org/data/childes/Eng-NA/Hall?f=zip`. Their source URLs, archive
hashes and download date are retained in
`/home/jason/talkbank-data/2026-09-07/download_inventory.json`.
They are authentic TalkBank files, but current corpus pages need not serve the
same transcript versions used by a historical childes-db export.

Most current files do contain a usable target age: 12,750 of 15,929 before our
recoveries. Within Eng-NA, 2,248 lack a current age; 1,294 of these have an ASR
flag in the raw-header audit. ASR does not explain every missing age.

Two directly inspected examples explain different mechanisms:

| Transcript | Historical metadata | Current live download |
| --- | --- | --- |
| Hall, `BlackPro/anc.cha` | Child age `4;09.`; child, investigator, mother and father roles | Different PID; anonymous `PAR0`/`PAR1`; no child age; marked unchecked ASR |
| NewmanRatner, PID `11312/c-00043594-1` | Target-child ID includes age `0;07.` | Same full PID, but only mother/investigator ID entries remain; target-child entry is absent |

For NewmanRatner, the old member is `Interviews/07/4269LP.cha`, while the current
member is `07/4269LP.cha`. There are 186 utterances in each, identical speaker
sequences and 96.24% normalized positional text agreement. The missing age is
absent in the raw current header; it is not a PyLangAcq age-conversion failure.
That case is already among the verified metadata recoveries.

## A separately preserved original Hall archive

The [official Hall page](https://talkbank.org/childes/access/Eng-NA/Hall.html)
explains that new ASR transcripts replaced the web versions in 2026 and have not
yet been cleaned and checked. It separately links
[Hall-orig.zip](https://talkbank.org/childes/access/Eng-NA/0docs/Hall-orig.zip).
That archive is now downloaded outside Git. Inspection found 40 real CHAT files,
39 with a child age, and UD-style morphology/dependency tiers. Forty macOS
sidecar files were ignored. The example `anc.cha` preserves the original PID and
age. See `legacy_mor/Hall-orig.provenance.json` for the source, hash and inspection.

This archive has not been substituted into the preserved first-run fits.
The matched follow-up does use it after transcript identity, age, source-hash
and utterance checks. An audit of all 98 official corpus pages also found
[McCune-orig.zip](https://talkbank.org/childes/access/Eng-NA/0docs/McCune-orig.zip).
It contains 52 CHAT files with ages; 47 have strong links to historical IDs.
The matched rows include 99,577 Hall utterances and 13,232 McCune utterances.
These archives have their own annotation provenance; they are not assumed to
share the current downloads' Stanza version.

## Interpretation

The first run established that the fitting code reproduces saved results on
saved pairs, and that using the live downloads produces different age curves.
It did not isolate a parser change on the original data. The follow-up anchors
all three analysis arms to the original CSV's ages and 2,728,212 matched
utterances. It holds the selected population fixed while comparing existing UD
annotations, spaCy on CHAT text, and spaCy on the original CSV text. This is a
verified intersection, covering 57.6% of the original analysis, rather than a
reconstruction of the entire historical corpus or its unrecorded parser version.
